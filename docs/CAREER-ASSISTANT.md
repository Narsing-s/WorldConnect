## Career Assistant\n\nThis phase adds a privacy-first career workspace. It performs browser-side resume section checks and skill extraction, role-based skill-gap suggestions, explainable matching against current published WorldConnect jobs, and curated interview practice questions.\n\nResume text is not sent to an external AI provider. The UI states this clearly and does not describe local scoring as an AI prediction. Saving is optional and requires an explicit consent checkbox. Saved resume text is stored in wc_career_workspaces with owner-only row-level security and no anonymous/public grants. Users can delete their saved workspace.\n\nApply supabase/migrations/20261120_private_career_workspace.sql before using private save. Browser-side analysis works before the migration is applied; saving displays a setup message until the table exists.\n\nRun npm run lint, npm run verify:platform, and npm run build. Test with two accounts to verify that one member cannot read, update, or delete another member's workspace.
